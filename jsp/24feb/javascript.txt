let salary = 30000;

    console.log("Eligible");

    console.log("Not Eligible");

Q32
Write a program using ternary operator:
 Check if number is positive, negative, or zero.

ans : 
let num = -5;

let result = num > 0 ? "Positive"
            : num < 0 ? "Negative"
            : "Zero";

console.log(result);

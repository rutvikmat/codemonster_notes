1. What is JavaScript? Mention any two features.

JavaScript is a client-side scripting language used to create dynamic and interactive web pages.
Features:

Interpreted language

Supports event-driven programming

2. How is JavaScript different from Java?
JavaScript	Java
Scripting language	Programming language
Interpreted	Compiled
Runs in browser	Runs on JVM
Dynamically typed	Statically typed
3. What are variables in JavaScript? Why are they needed?

Variables are containers used to store data values.
They are needed to store, update, and manipulate data during program execution.

4. Difference between var, let, and const
Keyword	Scope	Reassignment
var	Function	Yes
let	Block	Yes
const	Block	No
5. Use of typeof operator

It is used to determine the data type of a variable.

typeof 10   // "number"

6. Purpose of parseInt()

Converts a string into an integer.

parseInt("123")  // 123

7. Difference between alert() and console.log()

alert() → Shows message in popup box

console.log() → Displays output in browser console

8. What happens when confirm() is used?

It displays a confirmation dialog with OK and Cancel and returns:

true if OK

false if Cancel

9. Arithmetic operators in JavaScript

Used to perform calculations.

Examples:

+  -  *  /  %

10. Increment and decrement operators

++ increases value by 1

-- decreases value by 1

Example:

let x = 5;
x++; // 6
x--; // 5

A2. while Loop – Write 5 Programs
1. Write a JavaScript program to print numbers from 10 to 1 using while loop.
<!DOCTYPE html>
<html>
<body>
<script>
let i = 10;
while (i >= 1) {
  document.write(i + " ");
  i--;
}
</script>
</body>
</html>


2. Write a program to find the sum of digits of a number using while loop.
<!DOCTYPE html>
<html>
<body>
<script>
let num = parseInt(prompt("Enter number:"));
let sum = 0;

while (num > 0) {
  sum += num % 10;
  num = Math.floor(num / 10);
}

document.write("Sum of digits = " + sum);
</script>
</body>
</html>



3. Write a program to count the number of digits in a number using while loop.
<!DOCTYPE html>
<html>
<body>
<script>
let num = parseInt(prompt("Enter number:"));
let count = 0;

while (num > 0) {
  count++;
  num = Math.floor(num / 10);
}

document.write("Number of digits = " + count);
</script>
</body>
</html>


4. Write a program to reverse a number using while loop.
<!DOCTYPE html>
<html>
<body>
<script>
let num = parseInt(prompt("Enter number:"));
let rev = 0;

while (num > 0) {
  rev = rev * 10 + (num % 10);
  num = Math.floor(num / 10);
}

document.write("Reversed number = " + rev);
</script>
</body>
</html>

5. Write a program to print all odd numbers between 1 and 30 using while loop.
<!DOCTYPE html>
<html>
<body>
<script>
let i = 1;
while (i <= 30) {
  if (i % 2 !== 0) {
    document.write(i + " ");
  }
  i++;
}
</script>
</body>
</html>

Section B: Multiple Choice Questions (MCQs)
1. Which loop is guaranteed to execute at least once?
a) for
b) while
c) do-while
d) nested
ans- c) do-while

2. Which keyword is used to exit a loop immediately?
a) stop
b) exit
c) break
d) continue
ans- c) break

3. Which keyword skips the current iteration?
a) break
b) skip
c) pass
d) continue
ans- d) continue


4. Nested loops are mainly used for:
a) Decision making
b) Pattern printing
c) Function calling
d) Error handling

for(let i=1;i<=3;i++)

1.What is JavaScript? Mention any two features of JavaScript.
JavaScript is a high-level, interpreted programming language primarily used to make web pages interactive and dynamic. It runs in the browser and allows developers to control webpage behavior such as form validation, dynamic content updates, animations, and event handling.

Two features of JavaScript:

Dynamic Typing – Variables in JavaScript do not require explicit data types; the type is determined at runtime.

Event-Driven Programming – JavaScript can respond to user actions like clicks, key presses, and mouse movements using events.

2.How is JavaScript different from Java?

| Feature                 | JavaScript                           | Java                                              |
| ----------------------- | ------------------------------------ | ------------------------------------------------- |
| **Type**                | Interpreted, scripting language      | Compiled, object-oriented language                |
| **Execution**           | Runs in the browser (or Node.js)     | Runs on JVM (Java Virtual Machine)                |
| **Typing**              | Dynamically typed                    | Statically typed                                  |
| **Primary Use**         | Web development (frontend & backend) | Enterprise applications, Android, backend systems |
| **Object Model**        | Prototype-based                      | Class-based                                       |
| **Platform Dependency** | Platform-independent via browser     | Platform-independent via JVM                      |
| **Syntax**              | Lightweight and flexible             | Strict and verbose                                |
| **Concurrency**         | Single-threaded (event loop)         | Multi-threaded                                    |


3. What are variables in JavaScript? Why are they needed?

Variables are used to store data values so they can be reused and manipulated in a program.

Why they are needed:

-To store user input

-To hold calculation results

-To make code readable and reusable

Example:

let age = 20;
let name = "Alex";

4. Difference between var, let, and const
| Feature        | `var`           | `let`                 | `const`               |
| -------------- | --------------- | --------------------- | --------------------- |
| Scope          | Function scope  | Block scope           | Block scope           |
| Re-declaration | Allowed         | Not allowed           | Not allowed           |
| Re-assignment  | Allowed         | Allowed               | Not allowed           |
| Hoisting       | Yes (undefined) | Yes (not initialized) | Yes (not initialized) |

var x = 10;
let y = 20;
const z = 30;

5. Use of the typeof operator

The typeof operator is used to find the data type of a variable.

Example:

typeof 10;        // "number"
typeof "Hello";   // "string"
typeof true;      // "boolean"

6. Purpose of the parseInt() function

parseInt() converts a string into an integer.

Example:

parseInt("25");      // 25
parseInt("25.5");    // 25
parseInt("101", 2);  // 5


7. Difference between alert() and console.log()
alert()	console.log()
Shows popup dialog	Prints message in console
Blocks execution	Non-blocking
Used for user messages	Used for debugging

Example:

alert("Hello User");
console.log("Debug message");


8. What happens when you use confirm()?

confirm() displays a dialog box with OK and Cancel buttons and returns a boolean value.

OK → true

Cancel → false

Example:

let result = confirm("Are you sure?");


9. Arithmetic operators in JavaScript (with examples)

Arithmetic operators perform mathematical operations.

| Operator | Description    | Example |
| -------- | -------------- | ------- |
| `+`      | Addition       | `5 + 2` |
| `-`      | Subtraction    | `5 - 2` |
| `*`      | Multiplication | `5 * 2` |
| `/`      | Division       | `5 / 2` |
| `%`      | Modulus        | `5 % 2` |



10. Increment (++) and Decrement (--) operators

++ increases value by 1

-- decreases value by 1

Example:

let a = 5;
a++;   // a becomes 6
a--;   // a becomes 5


Pre vs Post:

let x = 5;
console.log(++x); // 6 (pre-increment)
console.log(x++); // 6 (post-increment, then x becomes 7)

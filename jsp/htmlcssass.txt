---- HTML ----


1. What is HTML? 
   HTML (HyperText Markup Language) is used to create and structure web pages. 
   It tells the browser how to display text, images, links, and other content

  • <!DOCTYPE html>
   <html>
      <head>
         <title>My First Page</title>
      </head>
      <body>
          <h1>Hello World</h1>
          <p>This is my first webpage.</p>
      </body>
    </html>

2. What is the difference between HTML and HTML5? 

   • HTML :-

	• Basic version used to structure web pages
	• No semantic elements like <header> or <footer>
	• No built-in support for audio and video
	• Limited form input types
	• Uses external plugins (like Flash) for multimedia
	• EX:
	<!DOCTYPE html>
	  <html>
	    <body>
  	       <div>Header</div>
  	       <div>Main Content</div>
            </body>
          </html>


  • HTML5 :-

	• Improved and modern version of HTML
	• Introduced semantic elements (<header>, <section>, <footer>, etc.)
	• Supports <audio> and <video> without plugins
	• Provides new form input types (email, date, number)
	• Supports localStorage and sessionStorage
	• EX:
        <!DOCTYPE html>
	  <html>
	    <body>
  	      <header>Header</header>
  	      <section>Main Content</section>
	    </body>
          </html>

4. What is the difference between <div> and <span>? 

   <div>:-
	• It is a block-level element
	• It takes full width of the page
	• It starts on a new line
	• It is mainly used to group large sections of content
	• Used for layout and structure
	• EX:
	     <div style="background-color: yellow;">
  	        This is a div element
	     </div>

	     <div style="background-color: lightgreen;">
  	        Another div element
	     </div>


    <span>:-

	• It is an inline element.
	• It takes only required width.
	• It does not start on a new line.
	• It is mainly used to style small parts of text.
	• Used inside other elements like <p>.
	• EX:
	     <p>
  		This is <span style="color: red;">important</span> text.
	     </p>

5. What is the difference between block and inline elements? 

   • Block Elements:-

	• Block elements start on a new line.
	• They take full width of the page.
	• We can set width and height.
	• They are mainly used for structure and layout.
	• Examples: <div>, <p>, <h1>
		• <p>This is a paragraph.</p>
		• <div>This is a div element.</div>
		• <h1>This is a heading.</h1>


  • Inline Elements:-

	• Inline elements do not start on a new line.
	• They take only required width.
	• Width and height usually cannot be set.
	• They are mainly used for styling small parts of content.
	• Examples: <span>, <a>, <b>, <i>

		<p>
  		   This is <span style="color:red;">red</span> text and
  		   <a href="#">this is a link</a>.
		</p>

6. What is the purpose of the doctype declaration? 

   • The <!DOCTYPE html> declaration tells the browser which version of HTML is being used.
   • It helps the browser to:
   • Display the webpage correctly
   • Follow proper HTML standards
   • Avoid errors in layout
   • Use standard mode instead of quirks mode

7. What is the difference between <b> and <strong>? 
  
   • <b> Tag:-
	• <b> stands for bold.
	• It makes the text bold only for styling purpose
	• It does not give any special importance to the text
	• It is used when we just want to highlight text visually
	• EX:
	     <p>This is <b>bold</b> text</p>


   • <strong> Tag:-
	• <strong> is used to show important text
	• It makes the text bold and gives meaning/importance
	• Search engines and screen readers treat it as important content
	• It is a semantic tag.
	• EX:-
              <p>This is <strong>important</strong> information</p>

10. What is the difference between id and class?

   • id:-
	• id is used to uniquely identify one single element.
	• It must be unique in a webpage.
	• Only one element can have a particular id.
	• In CSS, it is selected using #.
	• EX:
            • HTML:
		   <p id="heading">Hello World</p>

		   #heading {
  			color: red;
		    }


   • class:-
	• class is used to group multiple elements.
	• Many elements can share the same class name.
	• It is used when we want to apply the same style to multiple elements.
	• In CSS, it is selected using . (dot).
	• EX:
	    • HTML:
		   <p class="text">Hello</p>
		   <p class="text">Welcome</p>

	   • CSS:
		   .text {
  			color: blue;
		    }

12. What is the difference between localStorage and sessionStorage? 
        
   • localStorag:-
	• localStorage stores data permanently in the browser.
	• The data remains even after closing the browser.
	• It is used when we want to store data for a long time.
	• Data is saved as key–value pairs.
	• EX:
	    <script>
		localStorage.setItem("name", "Madhuri");
		console.log(localStorage.getItem("name"));
	    </script>


    • sessionStorage:-
	• sessionStorage stores data temporarily.
	• The data is removed when the browser tab is closed.
	• It is used when we want data only for one session.
	• Data is also stored as key–value pairs.
	• EX:
	     <script>
		sessionStorage.setItem("age", "25");
		console.log(sessionStorage.getItem("age"));
	     </script>

13. What is the difference between GET and POST? 

   • GET Method:-

	• GET is used to request data from the server.
	• Data is sent through the URL.
	• Data is visible in the browser address bar.
	• It is less secure.
	• EX:
	     <form method="GET" action="submit.html">
  		<input type="text" name="username">
  		<input type="submit">
	     </form>


   • POST Method:-
	• POST is used to send data to the server.
	• Data is sent in the request body.
	• Data is not visible in the URL.
	• It is more secure than GET.
	• Used for login forms, registration, etc.
	• EX:
	     <form method="POST" action="submit.html">
  		<input type="text" name="username">
  		<input type="submit">
	     </form>

17. What are the three types of CSS? 

   • There are three types of CSS:
	1. Inline CSS
	2. Internal CSS
	3. External CSS


   1. Inline CSS:-
	• CSS is written inside the HTML element.
	• It uses the style attribute.
	• It affects only that specific element.
	• EX:
	     <p style="color: red;">Hello World</p>


   2. Internal CSS:-
	• CSS is written inside the <style> tag.
	• It is placed inside the <head> section.
	• It affects the whole page.
	• EX:
	    <!DOCTYPE html>
	    <html>
		<head>
  		    <title>Internal CSS Example</title>

  		    <style>
    			p {
     			    color: green;
      			    font-size: 18px;
    			  }
  		   </style>

		</head>
		<body>
  			<p>This is an example of Internal CSS.</p>

		</body>
	    </html>


   3. External CSS:-
	• CSS is written in a separate .css file.
	• It is linked using the <link> tag.
	• It is best for large websites.
	• EX:

	   • HTML

		<!DOCTYPE html>
		<html>
		    <head>
  			<title>External CSS Example</title>
  			<link rel="stylesheet" href="style.css">
		    </head>
		    <body>
  			<p>This is an example of External CSS.</p>

		    </body>
		</html>

	  • CSS

		p {
  		    color: brown;
  		    font-size: 18px;
		  }

18. What is the CSS Box Model? 

   • The CSS Box Model is a concept that explains how every HTML element is treated as a rectangular box.
   • Each element has 4 parts:
	• Content – The actual text or image inside the element.
	• Padding – Space between content and border.
	• Border – Surrounds the padding and content.
	• Margin – Space outside the border.
	• The total size of an element = Content + Padding + Border + Margin.
	• EX:
	     <!DOCTYPE html>
	     <html>
		<head>
  		    <style>
    			div {
      			     width: 200px;
      			     padding: 20px;
      			     border: 5px solid black;
     			     margin: 30px;
      			     background-color: lightgray;
    			    }
 		    </style>
		</head>
		<body>
  		      <div>
    			This is Box Model Example
  		      </div>

		</body>
	     </html>

19. Difference between margin and padding? 

   • Margin:-
	• Margin is the space outside the element.
	• It creates space between elements.
	• It does not affect the background color of the element.
	• It pushes the element away from other elements.
	• EX:
	     <!DOCTYPE html>
	     <html>
		<head>
  		    <style>
    			div {
      			     background-color: lightblue;
      			     margin: 40px;
    			    }
  		    </style>
		</head>
		<body>
  		    <div>This box has margin</div>
		</body>
	    </html>


   • Padding:-
	• Padding is the space inside the element.
	• It creates space between content and border.
	• The background color covers the padding area.
	• It increases the internal space of the element.
	• EX:
	     <!DOCTYPE html>
	     <html>
		<head>
  		    <style>
    			div {
      			     background-color: lightblue;
      			     padding: 40px;
    			    }
  		    </style>
		</head>
		<body>
  		    <div>This box has margin</div>

		</body>
	    </html>

20. What is the difference between border and outline?

   • Border:-
	• Border is the line that surrounds the padding and content.
	• It is part of the CSS Box Model.
	• It takes space and affects the element’s size.
	• We can set width, style, and color
	• EX: 
	     <!DOCTYPE html>
	     <html>
		<head>
  		    <style>
    			div {
      			     border: 3px solid red;
      			     padding: 20px;
    			    }
  		    </style>
		</head>
		<body>
  		    <div>This box has a border</div>
		</body>
	    </html>


   • Outline:-
	• Outline is a line drawn outside the border.
	• It is not part of the box model.
	• It does not affect the element’s size.
	• It is mainly used for highlighting elements
	• EX:
	     <!DOCTYPE html>
	     <html>
		<head>
  		    <style>
    			div {
      			     border: 3px solid red;
			     outline: 3px solid blue;
      			     padding: 20px;
    			    }
  		    </style>
		</head>
		<body>
  		    <div>This box has border and outline</div>
		</body>
	    </html>

21. What is the difference between display: none and visibility: hidden?

   • visibility: hidden

22. What is position property? Explain all values.

   • The position property in CSS is used to control the location of an element on a web page.
   • It works with properties like top, bottom, left, and right.


   1. static:-
	• Default position of all elements.
	• Elements appear in normal document flow.
	• top, left, right, bottom will NOT work.
	• EX:
	     <div style="position: static; background: lightblue;">
  		  Static Position
	     </div>


   2. relative:-
	• Element moves relative to its normal position.
	• Original space is still maintained.
	• You can use top, left, right, bottom.
	• EX:
	     <div style="position: relative; top: 20px; left: 30px; background: pink;">
 		 Relative Position
	     </div>


   3. absolute:-
	• Positioned relative to the nearest positioned parent (not static).
	• Removed from normal document flow.
	• Does NOT keep original space.
	• EX:
	     <div style="position: relative; height: 150px; background: lightgray;">
  		<div style="position: absolute; top: 20px; right: 20px; background: orange;">
    		     Absolute Position
  		</div>
	     </div>


   4. fixed:-
	• Positioned relative to the browser window.
	• Stays fixed even when scrolling.
	• Removed from normal flow.
	• EX:
	     <div style="position: fixed; bottom: 0; right: 0; background: yellow;">
 		 Fixed Position
	     </div>


   5. sticky
	• Works like relative at first.
	• Becomes fixed when you scroll.
	• Requires top, left, etc.
	• EX:
	     <div style="position: sticky; top: 0; background: lightgreen;">
  		Sticky Position
	     </div>

24. What is Flexbox?

   • Creates responsive row/column layouts
   • EX:

25. What is the difference between Flexbox and Grid? 

   • Flexbox:-
	• CSS layout model
	• Uses display: flex; on parent
	• Aligns items using justify-content and align-items
	• Creates responsive row/column layouts
	• EX:
	    <div style="display: flex;">
               <div>Item 1</div>
                   <div>Item 2</div>
        </div>

   • Grid:-
 	   • Two-dimensional layout (row and column)
 	   • Best for full page layouts
 	   • Can control rows and columns together
 	   • Uses display: grid;
       • EX: 
	    <div style="display: grid; grid-template-columns: 1fr 1fr;">
                <div>Item 1</div>
                    <div>Item 2</div>
            </div>

26. What is z-index? 

    • z-index controls the stacking order of elements.
    • It works only on positioned elements (relative, absolute, fixed, sticky).
    • Higher z-index value appears in front.
    • Lower z-index value appears behind.
    • EX:
	 <div style="position: relative; width: 200px; height: 200px;">
  
  	    <div style="position: absolute; 
                  width: 100px; height: 100px; 
                  background: red; 
                  z-index: 1;">
  	    </div>

  	   <div style="position: absolute; 
                 width: 100px; height: 100px; 
                 background: blue; 
                 left: 40px; top: 40px; 
                 z-index: 2;">
           </div>

        </div>

    • Common values: translate(), rotate(), scale(), skew().
    • EX:

28. What is the difference between width and max-width?

   • width:-
	• Sets a fixed width for an element.
	• The element will always try to take that exact width.
	• Not fully responsive.
	• Can cause overflow on small screens.
	• EX:
	     <div style="width: 500px; background: lightblue;">
  		  Fixed Width Box
	     </div>


   • max-width:-
	• Sets the maximum width limit. 
	• The element can shrink on smaller screens.
	• More responsive.
	• Prevents overflow.
	• EX:
 	     <div style="max-width: 500px; background: lightgreen;">
     		 Responsive Box
	     </div>

29. What is overflow property?

   • overflow controls what happens when content is too large for its container.
   • It manages extra content inside an element.
   • Common values: visible, hidden, scroll, auto.
   • Mostly used when content exceeds width or height.
   

   • Overflow Values:
	1. overflow: visible (Default)
		• Content overflows outside the box.

	2. overflow: hidden
		• Extra content is hidden.

	3. overflow: scroll
		• Always shows scrollbars.

	4. overflow: auto
		• Shows scrollbar only when needed.
   • EX:
	 <div style="width: 150px; height: 80px; 
              background: lightgray; 
              overflow: auto;">
             This is a long text content that will not fit inside the small box.
         </div>

3.Logical opertors
--------------------
The logical operators are :
and or not

For boolean valuves types:
---------------------------

or -->  if atleast one input is true then the result is true
not --> complement or reverse of the input

eg;
print(False and False)
print(False and True)
print(True and False)
print(True and True)

eg;
print(False or False)
print(False or True)
print(True or False)
print(True or True)

eg;
print(not False )

For non-boolean types :
--------------------------

non-zero means True
empty string is always treated as False

4.bitwise operators
--------------------
1 byte = 8 bits
1 bit can store either 0 or 1

we can apply the fallowing operators bitwise
&   |  ^   ~  <<   >>

& --> and operator
'if both the bits are 1 then the result is 1 else result is 0'

| --> or operator
'if atleast one of the bit are 1 then the result is 1 else result is 0'

^ --> xor operator
'if the bits are different then result is 1 if the bits are same result is 0'

~ --> not operator
'the complement of the bit '


<< --> left shift operator
>> --> right shift operator

7.Special operators
---------------------
Python 3 has two special operator such as :

1. Identity operator
2. Membership operator


Identity operator
------------------
is --> is operator will check the address of the object and compares the addres 
based on the if address are same it will return true else false

is not --> same as is operator but gives the reversed result of it.

'''
a=10
print(a)
print(id(a))
b=20
print(b)
print(id(b))
'''

a=10
b=20
print(a is b)
print(a is not b)



Membership operator
--------------------
in --> this operator will check the given the data return true if the element is present else returns false
not in --> complement of in operator


eg;
s='today is very good day'
print(s)
print('z' in s)
print('z' not in s)

lst=[10,20,30]
print(lst)
print(10 in lst)
print(20 not in lst)


Oprator precedence 
----------------------
if multiple operators are present then which operator will be executed first is decided by
pemdas rule.


PEMDAS rule;
P : parenthisis
e : exponential
m : multiplication
d : division
a : addtion 
s : subtraction


eg;
print(3+10*2)
print((3+10)*2)
print(3+(10*2))

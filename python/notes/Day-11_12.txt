Set datatype
--------------
* If we want to represent a group of elements as a single entity where
*Insertion order is not preserved / unordered
*duplicates are not allowed
*indexing and slicing is not possible
*growable in nature
*homogenous and heterogenous elements can be stored
*where only immutable objects can be stored
*elements are represented with {} curly brackets
*we can also perform the set operations
*it is mutable in nature

Internal implementation of the set elements
----------------------------------------------
A set in python internally make use of set hashing process for storing the elements.
In hashing process there are always two components;
1.Mathematical hash function
2.A hash table

1.hash function : based on the calculation of this function the elements will be stored in the hash table
2.hash key : the end result of the hash function is hash key
3.hash table : it is an internal table where based on hash key the elements will be stored

nots: if in case if there are same hash key generated then it is called as "collision" and it will be resolved with
the help of open adderssing algorithm


Dictionary in python
----------------------
Dictionary is datatype in python where ;
*elements will be stored in the key:value pair
*insertion order is preserved but still it is unordered in nature
*make use of hashing process to store the elements
*suports both homogenous and heterogenous elements
*duplicate values are allowed but duplicates keys are not allowed
*it is growable in nature
*dict keys must be always immuatble objects and values can be anything
*dict is mutable in nature

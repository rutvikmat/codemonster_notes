3.Transfer stmts;
------------------
1.break;
---------
we can use break stmt inside the loop to break the loop execution based on some condition.

eg;
----
for i in range(1,11):
	if i==5:
		print('processing is enough plz break it')
		break
	print(i)


eg;
---
cart=[10,20,600,60,70]
for item in cart:
	if item>500:
		print('insufficient balance')
		break
		print(item)


2.continue;
-----------
we can use continue to skio the current iteration and continue with the
next iteration

eg;
for i in range(1,11):
	if i%2==0:
		continue
	print(i)


eg;
----
cart=[10,20,600,60,70]
for item in cart:
	if item>500:
		print('insufficient balance')
		continue
	print(item)


eg;
---
lst=[10,20,35,45,75,80,90]
for i in lst:
	if i%2==0:
		print('these are even numbers')
		continue
	print(i)

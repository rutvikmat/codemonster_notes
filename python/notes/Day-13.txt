Types of arguments :
-----------------------
There are totally 5 types of arguments as shown below:
1.Positional arguments
2.keyword arguments
3.default/optional argument
4.variable length argument
5.variable length keyword argument


1.Positional arguments
----------------------
These are the inputs or data provided to the function and while passing these arguments compulosrly we
should remember the position of the parameter, and any changes in the order will not give the expected result.

def power_of(num,power):
	return num**power


if __name__ == '__main__':
	print(power_of(2,5))
	print(power_of(5,2))

	
	
#2.keyword arguments
---------------------
In order to overcome the drawback of the positional arguments we can use the keyword argument
keyword ie paramter name itself will be used to pass the arguments

def power_of(num,power):
	return num**power

if __name__ == '__main__':
	print(power_of(num=2,power=5))
	print(power_of(power=5,num=2))
	




#3.default/optional argument
------------------------------
In any case if we want to fix the default value for the parameter then we can use 
default arguments
but,
if any non-default argument present after the default argument the it will give error

eg
---
def power_of(num,power=2):
	return num**power

if __name__ == '__main__':
	print(power_of(num=5))
	print(power_of(num=10))

if __name__ == '__main__':
	#general way of importing the module
	import Calc
	print(Calc.add(10,20))

	#Aliasing the module name
	import Calc as c
	print(c.add(10,20))

	#importing the specific function from the module
	from Calc import add
	print(add(10,20))

	#importing the mulitiple function from the module
	from Calc import add,sub
	print(add(10,20))
	print(sub(10,20))

	#importing the all function from the module
	from Calc import *
	print(add(12,12))
	print(mul(12,10))

Flow control statements in python;
--------------------------------------
There are 3 different types of flow control stmts in python such as;
1.conditional stmt
2.Iterative stmt
3.Transfer stmt

1.Conditional stmt;
---------------------
conditional statements consist of 3 variants such as:

1. if
------- 
syntax;
--------
if condition : statement

or 

if condition :
	statement1
	statement2
	statement3

eg;
#if condition
----------------
name=input('enter the name')
if name=='sagar':
	print('hello sagar how are you?')


2. if-else
-------------
syntax;
-------

if condition:
	action-1
else:
	action-2

*if the condition is true then action1 will execute if the condition is false action2 will execute

eg;
---
name=input('enter ur fav chocolate name')
if name == 'dairymilk':
	print('plz bring me the dairymilk chocolate..!')
else:
	print('plz bring me the ice-cream')
	


3.if-elif-else:
----------------
syntax;
------
if condition1:
	action1
elif condition2:
	action2
elif condition3:
	action3
else:
	default action


eg;
---
name=input('enter ur fav chocolate name')
if name == 'dairymilk':
	print('plz bring me the dairymilk chocolate..!')
elif name=='kitkat':
	print('plz bring me the kitkat chocolate..!')
elif name=='milkybar':
	print('plz bring me the milkybar chocolate..!')
else:
	print('plz bring me the ice-cream')


	
note: there is no switch case concept in python

2. Iterative stmts 
---------------------
if we want to execute a group of stmts multiple time then we will use iterative stmts

python supports two types:
1. for loop
2. while loop

1. for loop
-------------
syntax:
---------
for i in sequence:
	body 

sequence can be anything such as str,list,tuple,range,etc....!

eg:
s='sachinTendulker'
for i in s:
	print(i)

eg;

2. while loop
---------------
syntax;
---------
while condition:
	body

eg;
x=1
while x<=10:
	print(x)
	x=x+1

for i in range(1,11):
	print(i)

Note:
for loop: is used on the sequence when we know the number of iterations
while loop : number of iterations is based on the condition

do while loop is not there in python.

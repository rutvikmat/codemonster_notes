diff b/w append and insert function
-------------------------------------
append()
*adding the element to the end of the list
*can be added only one element at a time
*it accepts only one argument eg:    lst.append(element)

insert()
*adding the element to any random position in the list
*can be added only one element at a time
*it accepts only two argument eg:    lst.insert(index,element)

5.pop() function
-------------------
*It will delete the last element of the list if we dont give any argument
*It will accept the +ve and -ve index number and delete the corresponding element from the list
*pop will accept only one argument at a time and it should be a index number
*suppose we if give the index number which is not available then it will return 'indexerror'.
eg;
---
lst=[10,20,30,10,50]
print(lst)
lst.pop()#last element will be deleted
print(lst)
lst.pop(2)#using the +ve index number element can be deleted
print(lst)
lst.pop(-2)#using the -ve index number element can be deleted
print(lst)

eg;
---
lst=[10,20,30,10,50]
print(lst)
lst.pop(2,3)#last element will be deleted
print(lst)
TypeError: pop expected at most 1 argument, got 2

eg;
---
lst=[10,20,30,10,50]
print(lst)
lst.pop(6)#last element will be deleted
print(lst)
IndexError: pop index out of range



diff b/w remove and pop function;
----------------------------------
remove()
*using the element as the argument we can remove the element from the list
*suppose the element is not available in the list we will get 'value error'
*minimum one argument must given to the remove fn

pop()
*using the index number(+ve and -ve) as the argument we can remove the element from the list
*suppose the index number is not available in the list we will get 'index error'
*with zero argument pop fn will delete the last element in the list

2.sort()
---------
In the list by default insertion order is preserved.
If we want to sort the elements then by default it will sort in ascending order.

eg;

print(lst)
lst.sort()#ascending order
print(lst)

note:
for the string it will sort in the alphabetical order

eg;
----
s=['INDIA','PAKISTAN','SRILANKA','Australia']
print(s)
s.sort()
print(s)


eg:
---

4.WAP  to generate the fibonacci sequence up to nth term
---------------------------------------------------------
input --> 7
output --> [0,1,1,2,3,5,8,13]
logic -->{prevnumber+curnumber=nextnumber}

way-1
-------
n=int(input('enter the number '))
sequence=[0,1]
if n<=0:
  print('enter some +ve number')
while len(sequence)<=n:
  next_val=sequence[len(sequence)-1]+sequence[len(sequence)-2]
  sequence.append(next_val)

print('first ',n,'fibo numbers are ',sequence)

op
enter the number 7
first  7 fibo numbers are  [0, 1, 1, 2, 3, 5, 8, 13]

way-2
-------
num=7
prev,cur =0,1
print("Fibonacci series:",prev,cur,end=" ")
for i in range(1,num):
    next_val=prev+cur
    prev=cur
    cur=next_val
    print(next_val,end=" ")
print()
'''
op
Fibonacci series: 0 1 1 2 3 5 8 13

8.Write a Python program to compute the sum of digits of each number of a given list.
-------------------------------------------------------------------------------------
Original tuple:
[10, 2, 56]
Sum of digits of each number of the said list of integers:
14


way-1
------
lst=[10,2,56]
print('given list is ',lst)
print(sum(int(el) for i in lst for el in str(i) if el.isdigit()))

way-2

  for el in str(i):
    if el.isdigit():
      data.append(int(el))

9.wap to print the duplicated elements
----------------------------------------
Input : list = [10, 20, 30, 20, 20, 30, 40, 50, -20, 60, 60, -20, -20]
Output : output_list = [20, 30, -20, 60]'''

way-1
lst = [10, 20, 30, 20, 20, 30, 40, 50, -20, 60, 60, -20, -20]
print('given list is ',lst)
size=len(lst)
repeated=[]
for i in range(size):
  data=i+1
  for j in range(data,size):
    if lst[i]==lst[j] and lst[i] not in repeated:
      repeated.append(lst[i])

print('res is ',repeated)

10.Given a list of numbers, write a Python program to count positive and negative numbers in a List.
-----------------------------------------------------------------------------------------------------
Input: list1 = [2, -7, 5, -64, -14]
Output: pos = 2, neg = 3'''


eg;
----
lst = [2, -7, 5, -64, -14]
print('given list is ',lst)
pos,neg=0,0
for i in lst:
  if i >=0:
    pos+=1
  else:
    neg+=1

print('-ve num in list are ',neg)
